# Spark Data Projects: Healthcare, E-commerce & Supply Chain

A collection of three PySpark projects developed and executed on a Linux-based Hadoop environment using HDFS.

Each project works with a different data format and focuses on data quality checks and analytical processing.

## Projects

| Project      | Format  | Main Analysis                               |
| ------------ | ------- | ------------------------------------------- |
| Healthcare   | Avro    | Data quality, SQL analytics, Avro → Parquet |
| E-commerce   | Parquet | Sales funnel, revenue, cart abandonment     |
| Supply Chain | CSV     | Delivery performance, sales trends          |
